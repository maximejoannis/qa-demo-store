# Corrigé des défauts volontaires

> **Réservé aux formateurs.** Ce fichier peut être retiré du dépôt public sans impact sur l'application. Chaque défaut est implémenté dans une couche séparée (`src/backend/faults.js` côté API, `src/ui/faults.js` côté interface) ; le moteur de calcul n'en contient aucun. Les tests `FAULT-*` prouvent qu'un défaut se déclenche pour son compte et ne fuit pas vers les autres.

| Identifiant     | Compte        | Couche | Comportement attendu                                               | Comportement observé                                                                                        | Règle violée         |
| --------------- | ------------- | ------ | ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- | -------------------- |
| `FAULT-PRB-01`  | problem_user  | API    | Tri « Prix croissant » du moins cher au plus cher                  | Ordre inversé                                                                                               | ENG-CAT-03           |
| `FAULT-PRB-02`  | problem_user  | API    | Image propre à chaque produit                                      | Images des produits 2 (Smart Speaker) et 5 (Leather Wallet) inversées                                       | Exigence visuelle    |
| `FAULT-PRB-03`  | problem_user  | Web    | Les champs saisis sont conservés entre les étapes                  | Le nom est vidé en passant de l'étape Adresse à l'étape suivante ; la commande échoue ensuite en validation | WEB-CHK-01           |
| `FAULT-GLT-01`  | glitch_user   | API    | Réponse immédiate                                                  | 3 s de latence sur la connexion et sur chaque devis (panier, tunnel)                                        | Performance perçue   |
| `FAULT-GLT-02`  | glitch_user   | API    | Rejouer la même `Idempotency-Key` renvoie la même commande         | Une nouvelle commande est créée (double commande)                                                           | API-CHK-03           |
| `FAULT-ERR-01`  | error_user    | API    | Commande créée (201)                                               | Toujours `500` avec un corps `{"title":"Error","code":"ERROR"}`                                             | Gestion d'erreurs    |
| `FAULT-ERR-02`  | error_user    | Web    | Message d'erreur traduit qui dit quoi faire                        | Toujours « Error »                                                                                          | Qualité des messages |

| `FAULT-RND-02`  | rounding_user | API    | TVA ventilée par taux, HT + TVA = TTC par taux                     | Panier à plusieurs taux : HT et TVA recalculés sur le total à 20 %, différents de la ventilation affichée   | ENG-VAT-02           |

| `FAULT-I18N-02` | i18n_user     | Web    | Dates au format de la langue (« 12 octobre 2026 »)                 | Format américain `10/12/2026`                                                                               | WEB-I18N-01          |
